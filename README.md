# hxyfront-62008 烟花燃放结算台

散场后的燃放结算前端：编排师凭纸条逐节点登记批次、计划时刻与实际结果，由安全员确认；
哑弹进入待处置区，已燃弹体释放批次占用。

## 业务规则

- 预置三段节目、四批弹药、六个发射节点（数据来自 `src/storage.ts`）。
- 每个节点登记：批次、计划时刻、补录实际时刻、实际结果（已燃 / 哑弹）、安全员确认。
- 哑弹进待处置区；只有已燃弹体释放批次占用，面板汇总批次消耗、待处置数量与下一场可再用数量。
- 补录实际时刻后，「执行结算判定」按脚本顺序检查后续未确认节点：同点位相邻节点实际间隔须 ≥ 1.2 秒；
  冷却不够即停下，并标出被拦下的节点与相邻节点。
- 节目段内节点全部确认且冷却无冲突后可签收；已签收节目段锁定在原时刻，不再参与编辑与移动。
- 时间轴与点位平面图读取同一份节点记录；所有数据保存在浏览器 localStorage。

## 文件分工（三个业务文件）

- `src/settlement.ts` — 结算判定：时间解析、签收条件、1.2 秒冷却、批次台账汇总（纯函数）。
- `src/storage.ts` — 本地存储：预置数据与 localStorage 的读取 / 保存 / 清空。
- `src/useSettlement.ts` — 页面交互：登记、确认、签收、结算动作的 React Hook。
- `src/App.tsx` 仅负责面板组合（指标、节目段、节点登记、台账、待处置区、时间轴、点位图）。
